## 规则特征清单（读代码时识别这些 = 业务规则）

| 特征 | 示例 | 规则类型 |
|---|---|---|
| if/switch 分支含比较、校验 | `if (qty > order.qty)` | 校验规则 |
| 抛异常 + 业务文案 | `throw new BusinessException("入库数量超出")` | 校验/异常规则 |
| 金额/数量/日期运算 | `amount = price * qty` | 计算规则 |
| 状态字段赋值 | `order.status = APPROVED` | 状态规则 |
| 权限判断 | `if (!canApprove(user))` | 权限规则 |
| 自动触发（SQL insert/update 联动） | 审批后 `INSERT payable` | 自动触发规则 |
| 批处理入口逻辑 | main 方法中循环处理数据 | 批处理规则 |
