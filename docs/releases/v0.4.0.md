# Code2Business v0.4.0 发布说明

发布日期：2026-09-11

版本类型：一键自动化与客户总报告版（功能版本）；Web、CLI、Agent Skills 同步使用统一版本号

v0.4.0 的目标：让"从导入代码到拿到交付文档"不再需要理解产品内部分工。普通人导入代码后
点一次「一键分析」，即可自动完成扫描、AI 业务归纳和模块需求规格，并直接下载一份合并的
《客户交付总报告》（Word）。六个专项交付文档与模块需求规格 zip 保持不变。

## 新增

### 客户交付总报告（第七类交付文档）

- 位置：「文档与交付物」页顶部主入口；CLI `c2b docs <id> --type combined`；
  API `GET /projects/{pid}/documents/combined`。
- 内容：阅读说明 → 执行摘要（白话）→ 系统概览 → 业务功能（域→对象→动作）→
  业务流程与业务主线 → 核心业务规则 Top20 → 数据概览 → 程序入口概览（隐去代码位置）→
  验收清单 → 待确认事项 → 生成说明与可信度声明；草稿版附录保留完整规则清单。
- 口径：正式版仅包含人工已确认的业务知识（与既有交付文档一致）；草稿版含 AI 未确认项，
  适合内部评审。业务域、程序入口只出现一次，不再跨文档重复。

### 一键自动分析

- Web/Desktop：「一键分析」按钮（顶部与总览引导横幅），调用
  `POST /projects/{pid}/auto-run`，按项目顺序执行 扫描（如需）→ AI 标注 → 模块需求规格；
  复用每项目唯一后台任务槽，进度在流程条可见。
- CLI：`c2b pipeline <代码目录> --name <项目> --out <目录>` 一条命令完成全流程并输出
  全部 7 类交付文档（`--fmt md|word|both`，默认双格式）；`--no-ai` 只做确定性扫描；
  `--official` 按正式口径导出（无已确认规则时给出提醒）。
- 边界：未配置 AI（LLM API Key）时自动止于确定性扫描，并明确提示补配 Key 后可继续；
  正式交付仍以人工确认为边界，自动化只产出可核对的草稿知识。

### 按可信度一键确认

- 「流程与规则」页新增：设定可信度阈值（默认 ≥80），先预览将确认的条数，再一键确认。
- 只作用于「AI 识别（未确认）」状态的规则；已确认/已修改/已废弃/冲突的规则不受影响；
  每条写入与手动确认完全相同的确认审计流水（可追溯）。

### 帮助中心与可读性

- 新增「帮助」入口：三步上手指引、白话术语表（模块/调用边/业务域/规则卡片/置信度/
  V1-V4/R0-R3/草稿与正式/模块需求规格）、常见问题（包括数据去向说明）。
- LLM 设置弹窗补充面向新手的说明（含 DeepSeek 推荐）；常见错误（未配 Key、Key 无效、
  服务不可达、本地库忙、任务冲突）翻译为可操作的中文提示。
- 总览页移除与当前项目无关的硬编码数字；「文档与验收」页更名为「文档与交付物」。

## 改进

- **Word 导出重写**：Markdown 表格现在渲染为真 Word 表格（表头加粗、细边框、单元格内
  换行），全部 7 类文档的 Word 观感一致提升；此前表格被拍平为文本行。
- **网页预览升级**：文档预览从原始 Markdown 文本升级为渲染排版（表格/标题/列表），
  渲染前对内容做 HTML 转义，只放行表格换行符，防止注入。
- 「文档与交付物」生成记录持久化在本机浏览器中（按项目隔离，最多 60 条），
  不再离开页面即丢失。
- 流程条修复：批量模块分析运行时此前在流程条上没有任何显示（盲区），现在正确显示在
  「AI 标注」步骤；一键分析的 `auto:*` 阶段同样映射到对应步骤。

## 质量证据

- 93 项 Python 回归测试通过（v0.3.1 为 76 项；新增 17 项覆盖：总报告正式/草稿边界、
  Word 真表格与转义、auto-run 编排（mock LLM 全流程、未配 Key 止于扫描、项目/目录异常）、
  高可信确认 dry-run 与审计、流程条阶段映射、CLI 一条龙与项目复用）。
- Vue 生产构建通过。
- `c2b pipeline --no-ai --fmt md` 对样例 Java 仓库实测：7 份交付文档落盘，
  总报告含执行摘要与全部章节。

## 安装资产

本版本继续提供 Apple Silicon（arm64）未签名试用包与 Python wheel：

- `C2B-Desktop-v0.4.0-macos-arm64.dmg`
- `C2B-Desktop-v0.4.0-macos-arm64.dmg.sha256`
- `C2B-Desktop-v0.4.0-macos-arm64.zip`
- `C2B-Desktop-v0.4.0-macos-arm64.zip.sha256`
- `c2b-0.4.0-py3-none-any.whl`

CLI 一条龙用法：

```bash
pip install c2b-0.4.0-py3-none-any.whl
c2b pipeline /path/to/legacy-code --name 老系统 --out ./deliverables
```

未签名试用包仍可能需要在 Finder 中右键"打开"，或在"系统设置 → 隐私与安全性"中确认。
Developer ID 签名、公证、Intel/Universal 包、自动更新、登录、多用户角色和跨客户项目隔离
不在本版本范围内。
