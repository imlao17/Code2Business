# Code2Business v0.6.0 发布说明

发布日期：2026-09-12

版本类型：macOS Desktop 原生化重构；Web、CLI、Agent Skills 同步使用统一版本号

v0.6.0 将 C2B Desktop 从 Tauri（Rust 壳 + WebView 加载 Vue 页面 + ~100MB 浏览器内核）
重构为**完全原生的 SwiftUI 应用**：原生窗口、侧栏、菜单、目录选择器，无 WebView。
分析引擎不变——仍是 Web/CLI/Skills 共享的 `core/`，以 PyInstaller sidecar 内置于应用包，
仅监听 127.0.0.1:8123。对使用者：更小、更快、更像一个真正的 Mac 应用；数据目录与
bundle id 延续，直接覆盖安装即可。

## 原生版 v1 覆盖的核心闭环

- **导入**：本地代码目录（原生 NSOpenPanel，仅关联不复制）/ Git 地址 / zip 包。
- **一键分析**（⇧⌘R）：扫描 → AI 归纳 → 模块分析一条龙，六步流程条实时进度。
- **总览**：规模与业务知识统计卡、下一步引导。
- **流程与规则**：规则工作台——详情（15 字段 + 代码证据片段）、确认/修改（表单编辑）/
  废弃、批量确认、按可信度一键确认（阈值滑杆 + dry-run 预览）、导出已确认 Excel。
- **业务视图**：业务域/对象/流程、业务推演主线（原生步骤条）、数据表与 SQL 操作、待确认项处理。
- **文档与交付物**：客户交付总报告置顶（Word/Markdown 经 NSSavePanel 保存）、六类专项
  文档、草稿/正式开关、Markdown 原生预览。
- **设置与帮助**：LLM 服务配置（含测试连接，Key 沿用钥匙串存储）；三步指引与白话术语表。

v1 暂未进入原生界面（可用 CLI 或 Web 操作同一数据库）：模块需求规格批量分析、
AI 问答、R1-R3 运行证据录入。

## 架构

```
C2B Desktop.app
├── Contents/MacOS/c2b-desktop        ← SwiftUI 原生壳（desktop/app Swift Package）
└── Contents/Resources/c2b-api        ← Python 分析引擎（PyInstaller onefile）
```

- 壳职责与旧 Tauri 壳对齐：同一组 `C2B_*` 环境变量、8123 就绪轮询、软单实例、
  `C2B_DESKTOP_PARENT_PID` 孤儿防护、退出清理。
- Desktop 构建不再依赖 node/pnpm；`sh scripts/build-macos.sh`（PyInstaller → swift build
  → 组装 .app → zip/dmg）。版本号单一来源：`core/pyproject.toml`。
- Tauri 相关代码（`desktop/src-tauri`、desktop package.json）已移除；CI desktop job
  改为 `swift build` + `swift test`。
- Web 产品不受影响：Vue 前端与 Docker 部署原样保留，仅版本号随升。

## 质量证据

- Swift 单测 8 项通过（API 解码契约、sidecar 配置）；98 项 Python 回归通过（含 MCP 数据库重定向回归）。
- 端到端冒烟（`desktop/scripts/smoke-app.sh`）：隔离数据目录启动打包版 .app → 引擎就绪 →
  导入样例仓库 → `--no-ai` 一键分析 → 流程就绪 → 生成客户交付总报告 → 退出无孤儿进程。
- 真实 bundle 启动验证：`healthz` 报告当前版本；bundle id `com.lao17.code2business` 延续，
  旧版本用户数据无需迁移。
