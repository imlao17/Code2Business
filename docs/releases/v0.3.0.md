# Code2Business v0.3.0 发布说明

发布日期：2026-08-13

版本类型：正式仓库版本；macOS Desktop 安装资产为 Apple Silicon 未签名试用包

v0.3.0 首次提供无需登录、无需 Docker、双击即可运行的 C2B Desktop，并保持 Web、CLI、Agent Skills 共用
同一个 `core` 引擎。本版本适合个人本地分析、客户现场试点和现有三种产品的独立部署；它仍是单实例、单团队
定位，不代表已经具备多租户、项目隔离或角色权限。

## 版本对应关系

| 形态 | v0.3.0 的含义 | 本次 Release 资产 |
|---|---|---|
| C2B Web 工作台 | Docker/浏览器部署，支持可视化图谱、人工确认、运行证据与文档导出 | 使用本 tag 源码按 `web/deploy/README.md` 部署 |
| C2B Desktop | Web 工作台的 macOS 本地分发，不是第四套分析引擎 | arm64 DMG、ZIP 及各自 SHA-256 |
| C2B CLI | Python 命令行、自动化和批处理入口 | `c2b-0.3.0-py3-none-any.whl` |
| C2B Agent Skills | 由 Codex、Claude Code 等 Agent 编排扫描、语义与文档流程 | 仓库 `skill/`，内置相同 v0.3.0 wheel |

## 主要变化

- 新增 Tauri 2 + Vue + Python/FastAPI Sidecar 的 macOS Desktop；默认使用本地 SQLite，API 只监听
  `127.0.0.1:8123`，不需要登录、Docker 或 PostgreSQL。
- Desktop 使用 macOS 原生目录选择器关联源码，不复制大型仓库；从 C2B 删除项目不会删除原始代码目录。
- 导入和扫描保持为两个明确阶段：选择/导入代码后，由用户显式点击“开始扫描”。
- Desktop 可以连接云端 OpenAI Compatible、Anthropic Native 或本机/局域网兼容模型；模型 API Key 保存到
  当前用户的 macOS 钥匙串。
- 增加可复现的 ZIP/DMG 构建、SHA-256、Developer ID 签名、公证和 Gatekeeper 检查流程；正式发布脚本会
  拒绝把 Apple Development 证书当作公网分发证书。
- 打包时强制校验使用当前仓库 `core/src`，避免构建机残留的旧 wheel 被误打进 Desktop。

## macOS Desktop 资产说明

本次上传的 Desktop 资产适用于 Apple Silicon（M1/M2/M3/M4，`arm64`）：

- `C2B-Desktop-v0.3.0-macos-arm64.dmg`
- `C2B-Desktop-v0.3.0-macos-arm64.dmg.sha256`
- `C2B-Desktop-v0.3.0-macos-arm64.zip`
- `C2B-Desktop-v0.3.0-macos-arm64.zip.sha256`

这些安装资产已经完成真实启动、Sidecar 生命周期、DMG 完整性和 SHA-256 验证，但由于当前发布机没有
`Developer ID Application` 证书，**尚未进行 Developer ID 签名和 Apple 公证**。首次打开可能需要在 Finder
中右键选择“打开”，或在“系统设置 → 隐私与安全性”中确认。不要把它理解为已公证的公众分发包。

Intel 和 Universal 包不在本次 Release 中；文件名明确包含 `arm64`，避免发生架构误判。

## 安装与使用

### Desktop

1. 下载并打开 arm64 DMG；
2. 将 `C2B Desktop.app` 拖到 Applications；
3. 首次打开如被 Gatekeeper 拦截，按上面的未签名包说明确认打开；
4. 点击“新建项目 → 本地代码目录”，选择源码仓库；
5. 关联完成后显式开始扫描，再根据需要配置模型并运行标注。

### CLI

```bash
python3 -m pip install c2b-0.3.0-py3-none-any.whl
c2b --help
```

Web 与 Agent Skills 的独立安装方法分别见 `web/README.md` 和 `skill/README.md`。
